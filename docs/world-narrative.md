# 可执行世界的叙事投影

可执行世界同时服务规则结算和连续故事，但两者不能共用一段结果摘要。规则模块拥有状态、合法动作和已经发生的事件；故事流水线只解释这些记录，不替规则模块掷骰、移动、改变回合或决定胜负。

## 为什么规则结果不能直接成为正文

“掷出 3”“前进到第 12 步”足以重放规则，却没有说明现场发生了什么变化、人物为什么需要回应、这段文字在整场戏中承担什么作用。写作 Worker 只有这些材料时，只能在机械事实外添加动作修饰，或者把每个结果换一种说法复述；更多文风指令不会创造缺失的戏剧材料。

成熟桌面角色扮演规则通常先把随机结果变成局势变化，再共同叙述画面。Blades in the Dark 的行动检定先确定人物目标、危险位置和预期效果，结果产生成功、减效、复杂状况、机会丢失或更危险的位置；进度钟只显示已经由虚构局势形成的进展或威胁，不反过来替代虚构。Ironsworn 的 move 只在行动危险或不确定时触发，弱成功和失败附带代价，特殊骰面会带来意外复杂状况或机会，oracle 提供可结合既有故事解释的细节。Fate 的 scene aspect 则把场景中值得人物利用或会使人物受阻的具体事实变成可操作对象。

这些机制的共同点不是特定骰制，而是下面的顺序：

```text
人物目标或世界动作
  → 权威规则结算
  → 现场变化、压力、机会或关系后果
  → 各人物按自身认知独立回应
  → Host 直接编排，或导演选择本轮节拍
  → 连续场景正文
```

## 模块接口

世界模块从一批已经记录的事件生成 `PlayWorldNarrativeProjection`。Host 在任何模型看到它之前验证事件引用和人物范围。

- `facts` 是正文必须尊重的公开事实。每项事实引用一个或多个本轮世界事件，并标为 `essential` 或 `compressible`：每位人物的首次起飞、碰撞、到达终点和事件牌等场景转折必须明确保留行动者、数值与结果，普通航线位移、后续起飞和无效投掷可以和同类机械事件合并成时间流动；两者都不能改变最终结果。
- `cues` 是当前事实打开的叙事方向，分为现场变化、压力、机会和关系后果。Cue 不是已经发生的人物行动；只有被列入 `characterIds` 的人物 Worker 可以选择回应，空集合表示事件只改变现场而不开放人物额外行动，人物没有回应时正文不能把建议写成事实。
- `cadence` 决定事件批次是压缩过渡、完整场景节拍还是场景收束。过渡可以继续累积多个规则回合，到达安全上限后合并呈现；场景和收束立即进入写作流水线。
- `invariants` 是不要求写进正文、但任何叙述都不能违反的世界事实，例如场景只有一张棋盘、各回合共用一枚骰子。Host 校验稳定 id 和内容后把它们交给正文与编辑 Worker。

Host 在一句或最多相邻六句中核对 `essential` 事实的语义词组和全部数值，使正文可以先建立行动者，再用有限的现场动作连接骰点与结果；窗口仍须同时恢复人物、关键数值和落定结果，不能从整篇文字的不同位置拼接事实。物件上明确由“写着”“刻着”“画着”等词引出的引号文字属于现场标记，不进入人物对白白名单；其余引号发言仍须逐字来自声音审校。只有同一局部无法恢复必要事实时才退回世界模块提供的事实文本，不能因为正文使用正常的场景节奏就覆盖已经合格的段落。

没有 cue、人物公开动作、获准对白或 `essential` 事实的 `transition` 使用紧凑正文路径：正文与必要的编辑使用结构档，只写一个自然段、二至四句且不超过 320 个字符，把相似规则动作合成时间流动。单次 `compressible` 骰点可以省略；一旦写出点数就必须采用事件中的真实值，破折号、省略号等缺值占位会触发编辑，编辑后仍不合格则退回完整的 Host 事实稿。出现 cue、人物材料、`essential` 事实、碰撞或胜负收束时继续使用完整场景路径。

需要跨回合保留的选择不能只写成 cue。世界模块另以 `characterOpportunities` 投影当前人物拥有的未决机会；每项机会保存稳定 id、来源事件、所有者、可回应人物、使用条件及 `available` 或 `retained` 状态。人物 Worker 必须结构化选择使用、保留或放弃，Host 只把最终公开正文中确实存在所需台词的使用决定交回模块。人物世界投影继续显示本人机会的 `used` 或 `declined` 终态，但终态不会重新进入可处置列表。机会处置与故事事件在一次工作区保存中提交；声音审校拒绝台词、正文遗漏台词或流水线中断都不会消耗机会。其他人物只能看到公开的来源事件，不能读取所有者的机会状态。

叙事投影必须能从持久化世界事件重建。随机出现的风、访客、故障或事件牌如果改变现场，世界模块要先把它记录为事件；不能只在临时 prompt 中告诉模型。这样重试、重启、人物认知投影和最终历史引用同一事实来源。

## 人物和正文

人物 Worker 继续只接收人物档案、该人物可见的事实、获准历史和世界投影。`cadence` 只控制正文篇幅，不授予人物公开反应；存在该人物可回应的 cue 时，人物才可以提出一个已经由当前处境引起的非规则行动或对白意图。公开行动必须已经完成并在没有对白时仍留下可观察结果；目光、姿态和等待接话不单独构成行动。掷骰、移动棋子和其他规则动作仍只能从 Host 公布的稳定动作 id 中选择。

导演只接收公开事实、cue、人物公开行动和结构化说话意图，不接收人物观察或私有洞察。它可以省略没有信息增长的回应，不能把并行人物提案伪造成彼此听见后的连续问答。没有故事图或伏笔义务且只启用一个正文分区的自动世界回合由 Host 直接编排公开行动和至多一个说话意图，不调用没有决策空间的导演。正文 Worker 和最终编辑除写作材料外还接收 Host 汇总的校验材料，其中保留事实的事件序号与保留方式、逐条事件数值、世界不变量、获准人物行动、未获准新增行动的人物和逐字对白；重复事件不能被误写成多个物体，不同结果不能被概括为相同，未获准的具名人物行为必须删除。段落数量由 `cadence` 和已发生事件的进展决定；完整场景可以在人物保持沉默时使用多个自然段，不能因为没有附加人物行动或获准对白就压成规则摘要。正文或编辑若吞掉一项 `essential` 事实或其中的数值，Host 保留上一份完整草稿；连续无效投掷等 `compressible` 事实仍可自然合并。

## 飞行棋纵切片

第一方飞行棋把以下结果标为完整场景：棋局开场、第一架飞机起飞、棋子碰撞、飞机到达终点和棋局结束。普通移动属于可累积的过渡。规则核心中的开场和首次起飞只改变呈现节奏；资源配置可以另用事件牌在这些里程碑增加人物 cue。碰撞、事件牌和终局带来实际选择或关系后果时才开放人物回应。

内置飞行棋世界资源带有三张结构化事件牌。本局第一架飞机离开基地时，一张只露出问号背面的折签从棋盘下滑出半截；这项公开事实没有人物回应权限，并作为未完现场线索持续进入世界投影。在没有新事件改变它的后续回合，模块把折签的位置、朝向、可见内容与处置状态投影为只读叙事不变量，人物和正文不能让它自行挪动或重新引发反应。第一架木机停在航线第 8 步时，底座把同一张折签完整带出，前置关系随新事件一起保存，随后向行动人物公开一次可使用、保留或放弃的提问机会；对手要等问题通过声音审校并实际出现在正文后才获得回答前提。连续四个角色回合都没有飞机起飞时，规则模块记录风掀起棋盘一角、基地木机随之晃动，只让触发本轮的行动人物决定如何压稳棋盘。旧棋局若已经记录折签事件但还没有机会字段，模块按事件 id 和所有者恢复同一个稳定机会，不重新触发事件牌。事件牌支持连续回合无棋可走、飞机离开基地、棋子停在指定步数、碰撞和指定数量棋子抵达终点等触发条件，并把事实标题与摘要、cue 类型、可回应范围、持久机会的使用方式、可选前置牌及是否重复分别保存；缺失引用和循环前置关系无法装入。后继牌只有在前置牌已经形成权威世界事件后才可触发，仍有后继牌未触发的已发生事件持续作为未完公开线索，事件保存在世界日志中，所以重试和重启不会重新抽取或改变现场。

当前场地编辑器以卡片形式编辑这些字段，保存时由 Host 用场地 revision 检查并让规则模块重新验证配置；当前棋局状态和既有事件保持不变。飞行棋事件牌支持连续无合法移动、飞机离开基地、棋子停在指定航线步数、发生碰撞和行动人物达到指定终点棋子数五种触发条件；回应范围支持触发人物、其他棋手或所有在场人物。触发者来自引发事件的权威日志，不使用结算后可能已经切换的当前行动者。后续要让回应范围支持指定人物槽位，并让故事地图节点也能约束事件牌。事件牌必须引入新的选择、信息、资源变化或关系后果；只提供天气、目光和手势等装饰不构成有效 cue。

## 验收

- 四个连续无效回合只产生一个可发展的场景压力，不生成四段点数播报。
- 世界事实和 cue 都引用真实事件序号；未知序号或未知人物在进入模型前被拒绝。
- 世界不变量拥有稳定且不重复的 id；正文和编辑能区分事件次数、事件数值与物体数量。
- 同一事件对每个人物的输入按 `characterIds` 和人物认知过滤，不能借导演信息补全。
- 导演输入不含人物观察与私有洞察；私有变化只进入所属人物的持久分区。
- 人物没有提出公开反应时，导演和正文不能把 cue 当作已经发生的动作。
- 第一架起飞、碰撞和终局能够结束过渡累积并形成新的场景节拍；只有后两者自动授权人物回应。
- 第一架起飞必须同时呈现促成起飞的骰点和棋子离开基地后的落点，不能只展示结算后的棋盘快照。
- 普通过渡只占一个紧凑自然段；没有信息增长的投掷可以合并或省略，正文不能保留缺失点数的占位符。
- 物件上的刻字、题签和标记不会被误删为未获准对白；人物直接发言仍只能来自声音审校。
- 重试与重启重放同一世界事件，不重复抽取事件牌或改变现场事实。
- 后继事件牌不能在前置事件发生前触发；未完公开线索持续进入人物和导演世界投影，后继牌触发后结束该项未完状态。
- 事件牌前置引用必须存在且无循环；不开放人物回应的现场变化仍能形成场景，但不能授予任何人物额外行动。
- 未完线索在没有新世界事件的回合只作为只读状态；正文不能让物件自行变化，也不能让人物仅因旧线索仍在场而重复反应。
- 紧凑规则过渡若补写骰子交接、无授权的目光或手势、未记录的物件变化，必须进入编辑；编辑结果仍包含这些内容时退回 Host 的世界事实稿。
- 落格、碰撞和终点进度事件只由本次规则结算触发；编辑配置不会回溯旧日志补抽事件牌。
- 正文只有事件牌实际授权的人物可以新增行动；其他人物可以承担已记录的规则动作或获准对白，不能被补写目光、表情、姿态或停顿。
- 未决机会只进入所有者的人物投影；保留后会在所有者后续获准回应的回合重新出现，明确放弃后不再出现。
- 提问机会只有在目标人物和最终可见问题都存在时才能变为已使用；候选台词被审校拒绝时保持原状态，对手在问题公开前没有回答前提。
